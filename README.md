# Personal website

One-page static site. Plain HTML and one CSS file. No build step.

## Preview locally

```bash
open index.html
```

## Deploy on GitHub Pages

1. Create a GitHub repo named `slvx17.github.io` and push this folder to it.
2. Open the repo on GitHub, then Settings, then Pages.
3. Under Build and deployment, set Source to "Deploy from a branch". Pick `main` and `/ (root)`, then save.
4. Wait about a minute. The site is live at `https://slvx17.github.io`.
